# 01-basics — Foundational C++ Syntax, I/O & Namespaces

> Comprehensive C++ implementations exploring foundational c++ syntax, i/o & namespaces.

## Programs in this Module

| Source File | Description | Compilation Command |
|---|---|---|
| `01_hello_modern.cpp` | Standard input/output streams with std::cout and std::cin | `g++ -std=c++17 -Wall 01_hello_modern.cpp -o run && ./run` |
| `02_namespaces_scope.cpp` | Namespaces declaration, resolution (::), avoiding using namespace std | `g++ -std=c++17 -Wall 02_namespaces_scope.cpp -o run && ./run` |
| `03_type_inference_auto.cpp` | Type inference using auto, decltype, and const qualifiers | `g++ -std=c++17 -Wall 03_type_inference_auto.cpp -o run && ./run` |
